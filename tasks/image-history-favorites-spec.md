# 历史图片编辑回填与收藏分类规格

## 目标

- 用户点击生成历史中的“再次编辑”后，在生成参数的参考图区明确看到该图片及“编辑原图”标识。
- 生成历史图片可收藏或取消收藏，状态以后端资产元数据为准。
- 产品素材可按图片类型筛选；该筛选可与“仅收藏”等现有条件组合。

## 交互规则

- “编辑原图”使用任务创建接口的 `editSourceAssetId` 提交，不加入只允许 `REFERENCE` 资产的 `referenceAssetIds`。
- 用户可在参考图区取消本次编辑原图；取消后下一次提交恢复为普通生成任务。
- 收藏按钮在请求期间禁用，后端确认后才更新图标和可访问名称。
- 素材筛选项按主图、A+ 图片、场景图、细节图、尺寸图、卖点图、宣传图、对比图展示。

## 接口契约

- `GET /api/v1/projects/{projectId}/assets` 新增可选查询参数 `imageType`。
- `imageType` 可与 `kind`、`favorite`、分页参数组合；兼容参数 `category` 与 `imageType` 含义一致。
- 素材响应中的 `category` 和 `imageType` 都表示资产当前的最终图片分类。生成任务上的原始 `imageType` 仅作为生成记录保留，不决定资产修改后的归属。
- 修改资产分类后，产品素材和生成历史都按新分类查询；旧数据分类无效时才回退到来源任务类型，仍无法识别时归入主图。
- 收藏继续复用 `POST/DELETE /api/v1/assets/{assetId}/favorite`，不新增收藏数据表。

## 验收标准

1. 点击历史图片编辑后，页面参考图区显示正确缩略图、文件名和“编辑原图”。
2. 提交编辑时仍发送 `editSourceAssetId`，不会把生成图放进 `referenceAssetIds`。
3. 历史图片收藏成功后按钮切换为“取消收藏”，失败时保留原状态并显示简体中文错误。
4. 产品素材使用“仅收藏 + 图片类型”组合筛选时，请求和结果均按组合条件生效。
5. 图片类型筛选保持租户和产品边界，不返回其他产品或租户任务的分类信息。
6. 修改生成图片的分类后，图片从原分类的生成历史和素材列表中移除，并出现在新分类中。
